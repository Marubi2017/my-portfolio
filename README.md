# Getting Started

This project contains source for my portfolio website, where I showcase my software engineering projects and professional experience. The website was built using HTML, JavaScript/TypeScript, and CSS, and is deployed on Vercel.

## Setting Up The Project
 To run the server:
 
 ```
     npm install

     npm start 
```
